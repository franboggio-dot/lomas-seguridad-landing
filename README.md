# Lomas Sistemas de Seguridad

Landing page para Lomas Sistemas de Seguridad, con sede en Córdoba, Argentina.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm start
```

Vite genera el sitio en `dist/`. Express sirve ese build en `/` y conserva las rutas existentes de API y administración.
